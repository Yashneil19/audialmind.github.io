What is a Signal? Intuition First

Before equations, understand what a signal actually is — variations of a quantity over time or space. Audio, images, radio waves — everything is a signal.

Time Domain vs Frequency Domain

The core mental model shift: the same signal can be viewed as amplitudes over time OR as a mix of frequencies. Both are equally real.

▶ Veritasium — Fourier Transform

The Fourier Transform — Math Demystified

Work through the actual DFT formula. You don't need to memorize it — you need to understand what the integral is asking: "how much does this frequency pattern correlate with my signal?"

▶ DFT Step by Step 📖 Better Explained Guide

FFT & Spectrograms in Python

Implement your first FFT with NumPy, plot a spectrogram of an audio file. See the theory materialize as code and visual output.

🐍 SciPy FFT Tutorial 🔊 Librosa Spectrogram

Sampling, Aliasing & Nyquist Theorem

Digital audio is sampled. Understand why 44.1 kHz is the standard, and what happens when you sample too slowly — aliasing artifacts.

▶ Sampling Theorem Explained ◎ Pudding — Waveforms Guide

openSMILE Deep Dive

Industry-standard feature extractor

openSMILE (open-source Speech and Music Interpretation by Large-space Extraction) is developed by the audEERING GmbH team and has been the backbone of every INTERSPEECH Computational Paralinguistics Challenge (ComParE) since 2009. It extracts over 6,000 acoustic features from a single audio file using a config-driven pipeline.

Config / Feature Set Feature Count Use Case Notes
ComParE_2016 6,373 features SER, emotion, health The competition standard. Overkill for quick experiments but the benchmark for papers.
eGeMAPS 88 features SER, clinical speech Minimalist, interpretable, and theoretically grounded. Recommended starting point.
GeMAPS 62 features Paralinguistics Predecessor to eGeMAPS. Slightly less features. Use eGeMAPS instead.
GeMAPSv01b 62 features Paralinguistics, SER Updated variant with corrected loudness calculation.
emobase 988 features Emotion recognition Middle ground between eGeMAPS and ComParE. Good for rapid prototyping.

Process a Full Dataset Folder
opensmile · Python · Batch Extraction
Extract features from every .wav file in a dataset folder (e.g. RAVDESS) and compile into a single DataFrame ready for sklearn. This is your actual data pipeline.
import opensmile, os, pandas as pd smile = opensmile.Smile( feature_set=opensmile.FeatureSet.eGeMAPSv02, feature_level=opensmile.FeatureLevel.Functionals, ) rows = [] for root, _, files in os.walk("ravdess/"): for f in files: if f.endswith(".wav"): path = os.path.join(root, f) label = f.split("-")[2] feat = smile.process_file(path) feat["label"] = label rows.append(feat) df = pd.concat(rows).reset_index(drop=True) df.to_csv("features.csv", index=False)

Train an SVM on openSMILE Features
sklearn · SVM · RBF Kernel
Once you have your features.csv, training the baseline SVM takes under 10 lines. Use StandardScaler — SVM is sensitive to feature scale. RBF kernel usually outperforms linear for eGeMAPS.
from sklearn.svm import SVC from sklearn.preprocessing import StandardScaler from sklearn.model_selection import cross_val_score import pandas as pd df = pd.read_csv("features.csv") X = df.drop("label", axis=1).values y = df["label"].values X_scaled = StandardScaler().fit_transform(X) svm = SVC(kernel="rbf", C=1.0, gamma="scale") uar = cross_val_score( svm, X_scaled, y, cv=10, scoring="balanced_accuracy" ) print(f"UAR: {uar.mean():.3f} ± {uar.std():.3f}")

Feature Importance with Random Forest
sklearn · RandomForestClassifier
Train a Random Forest on your openSMILE features and extract feature importances. Tells you which of the 88 eGeMAPS features matter most for your specific task.
from sklearn.ensemble import RandomForestClassifier import pandas as pd, matplotlib.pyplot as plt df = pd.read_csv("features.csv") feature_cols = [c for c in df.columns if c != "label"] X, y = df[feature_cols], df["label"] rf = RandomForestClassifier(n_estimators=200, random_state=42) rf.fit(X, y) importances = pd.Series( rf.feature_importances_, index=feature_cols) importances.nlargest(20).plot(kind="barh", figsize=(10,6), color="#a855f7") plt.tight_layout(); plt.show()
