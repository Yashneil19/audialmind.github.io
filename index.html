Self-Attention — The Core Mechanism

What makes transformers different

Before diving into specific models, understand what transformer self-attention does that CNNs cannot: it computes relationships between every pair of time steps simultaneously. This is why a transformer can connect the opening vowel of an utterance to its closing syllable to model prosody — a CNN's receptive field grows slowly with depth.

Query (Q)
"What am I looking for?"
Each time frame projects its hidden state to a query vector
Represents what information the current frame needs from others
Q = XW_Q
Key (K)
"What do I contain?"
Each time frame broadcasts what information it can provide
Dot product Q·K gives relevance score between any two frames
K = XW_K
Value (V)
"What do I give?"
The actual content retrieved when attention is paid
Weighted sum of V vectors, weights = softmax(Q·K/√d)
V = XW_V
Multi-Head
H parallel heads
Each head learns different attention patterns (rhythm, pitch, phoneme)
Wav2Vec2 uses 12 heads, 768-dim each
concat → linear

Fine-tune Wav2Vec2 for Emotion Classification
HuggingFace Transformers · PyTorch
Load the base model, freeze the CNN feature extractor, add a pooling + classification head, and fine-tune only the transformer layers and head. This is the standard recipe for small dataset SER.
from transformers import Wav2Vec2Model import torch.nn as nn class W2V2Classifier(nn.Module): def __init__(self, n_classes): super().__init__() self.encoder = Wav2Vec2Model.from_pretrained( "facebook/wav2vec2-base" ) # Freeze CNN feature extractor self.encoder.feature_extractor._freeze_parameters() self.proj = nn.Sequential( nn.Linear(768, 256), nn.ReLU(), nn.Dropout(0.3), nn.Linear(256, n_classes) ) def forward(self, x, mask=None): out = self.encoder(x, attention_mask=mask) pooled = out.last_hidden_state.mean(dim=1) return self.proj(pooled)

HuBERT Feature Extraction (No Fine-tune)
HuggingFace · HuBERT · Frozen Encoder
Extract HuBERT embeddings without fine-tuning the transformer at all — just train a lightweight classifier head on the mean-pooled hidden states. Surprisingly competitive and very fast to iterate on.
from transformers import HubertModel, Wav2Vec2FeatureExtractor import torch model = HubertModel.from_pretrained("facebook/hubert-base-ls960") extractor = Wav2Vec2FeatureExtractor.from_pretrained( "facebook/hubert-base-ls960" ) model.eval() with torch.no_grad(): inputs = extractor(audio, sampling_rate=16000, return_tensors="pt", padding=True) out = model(**inputs) # Mean-pool all hidden states emb = out.last_hidden_state.mean(dim=1)

Extract all intermediate hidden states and train a separate linear probe on each to find which transformer layer best encodes emotion. The optimal layer is typically 6–9 for SER tasks in base-size models.

Weighted Layer Fusion (SUPERB-style)
PyTorch · Learnable Layer Weights
Instead of picking one layer, learn a weighted sum across all transformer layers. This is the approach used by the SUPERB benchmark and often outperforms using only the final layer by 2–5% UAR.
class WeightedLayerFusion(nn.Module): def __init__(self, n_layers=13): super().__init__() self.weights = nn.Parameter( torch.ones(n_layers) / n_layers ) def forward(self, hidden_states): # hidden_states: list of (B, T, D) × n_layers w = self.weights.softmax(dim=0) stacked = torch.stack(hidden_states, dim=1) # (B, n_layers, T, D) fused = (stacked * w[None,:,None,None]).sum(dim=1) return fused.mean(dim=1) # (B, D)
