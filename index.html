Recommended Learning Path

Start here
01

What is a Signal? Intuition First

Before equations, understand what a signal actually is — variations of a quantity over time or space. Audio, images, radio waves — everything is a signal.

▶ 3Blue1Brown — Fourier Intro ◎ Circles & Sines (visual)
02

Time Domain vs Frequency Domain

The core mental model shift: the same signal can be viewed as amplitudes over time OR as a mix of frequencies. Both are equally real.

▶ Veritasium — Fourier Transform 🖼 Animated decomposition
03

The Fourier Transform — Math Demystified

Work through the actual DFT formula. You don't need to memorize it — you need to understand what the integral is asking: "how much does this frequency pattern correlate with my signal?"

▶ DFT Step by Step 📖 Better Explained Guide
04

FFT & Spectrograms in Python

Implement your first FFT with NumPy, plot a spectrogram of an audio file. See the theory materialize as code and visual output.

🐍 SciPy FFT Tutorial 🔊 Librosa Spectrogram
05

Sampling, Aliasing & Nyquist Theorem

Digital audio is sampled. Understand why 44.1 kHz is the standard, and what happens when you sample too slowly — aliasing artifacts.

▶ Sampling Theorem Explained ◎ Pudding — Waveforms Guide

"The Fourier transform is not just a mathematical tool — it's a way of seeing. Once you understand it, you'll see frequencies hiding inside everything."

— Alan V. Oppenheim, Discrete-Time Signal Processing

Library Free
Librosa — Audio Analysis in Python
librosa.org · pip install librosa
The de-facto Python library for audio analysis. Loads audio files, computes spectrograms, MFCCs, chroma features, beats, and more. You'll use this for the entire AudialMind project.
View Docs →
Library Free
SciPy FFT Module
scipy.fft · Part of SciPy
The fastest and most correct FFT implementation for Python (wraps FFTPACK/FFTW). Essential for any custom signal processing work. scipy.fft.fft() is all you need to start.
View Docs →
Library Free
Matplotlib for Signal Visualization
matplotlib.org · Already installed
You'll use plt.specgram(), plt.psd(), and librosa.display.specshow() constantly. This week: practice plotting a raw waveform, an FFT magnitude spectrum, and a spectrogram side by side.
View Gallery →
⭐ Must Have
Software Free
Praat — Phonetics & Speech Analysis
fon.hum.uva.nl/praat · Windows / Mac / Linux
The gold-standard tool used by linguists, phoneticians, and audio researchers worldwide. Praat lets you visualize waveforms, spectrograms, pitch contours, formants, and intensity in real time — all without writing a single line of code. Ideal for building strong visual intuition for how speech signals behave before implementing analysis in Python. Also scriptable via its own Praat scripting language for batch processing.
Download Praat →
